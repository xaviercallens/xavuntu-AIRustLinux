# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique work rather than people,
and welcome newcomers, including people learning Rust or Lean and people
learning to use AI agents responsibly.

Specific to this project: honesty about evidence is part of conduct. Presenting
fabricated results, simulations as measurements, or an AI agent's unverified
output as verified is a conduct issue, not only a technical one.

Report conduct concerns to the maintainer at callensxavier@gmail.com.
Reports are handled confidentially.
