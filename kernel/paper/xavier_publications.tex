\section{Executive Research Overview}
This dossier centralizes the systems engineering and formal verification research developed by Xavier Callens across public and private codebases. Operating at the intersection of bare-metal operating system safety, formal computer-checked mathematics (Lean 4), high-performance solvers, and accelerated machine learning runtimes (RISC-V \& Google TPUs), this body of work addresses the fundamental ``safety-versus-performance'' tax. 

By utilizing Rust's affine type system for zero-cost resource management, and bounding hardware-abstraction boundaries via automated theorem proving, these projects prove that mathematical security guarantees do not concession, but rather unlock, compiler-guided systems optimizations.

\section{Consolidated Publications \& Articles}

\subsection{1. RunuX-AI: Systolic-Aware ML Runtimes}
\textit{\small Status (2026-09-26): the full paper is quarantined at \texttt{paper/quarantine/runux\_ai\_paper.tex} pending confirmation that \texttt{scripts/run\_benchmarks.sh --simulate-tpu} reproduces the figures below; see \texttt{docs/roadmap/PAPER\_VERIFICATION\_TODO.md}.} \\
\textbf{Title:} RunuX-AI: A Unified, Memory-Safe Rust Runtime for High-Efficiency Federated LLM Execution across Edge RISC-V and Cloud Systolic TPUs \\
\textbf{Target Venue:} MLSys '27 / IEEE Transactions on Parallel and Distributed Systems (TPDS) \\
\textbf{Repository Reference:} Private, \url{github.com/xaviercallens/runux-ai-runtime} \\
\textbf{Core Contributions:}
\begin{itemize}
    \item \textbf{Unified Memory-Safe HAL:} Trait-based, compile-time backend generic dispatch spanning RISC-V Vector processors and Cloud TPU PJRT.
    \item \textbf{PolarQuant \& QJL:} Lossy 3-bit block-wise KV-cache quantization using orthogonal Householder rotations and scale error correction, achieving $<0.05$ reconstruction error (simulated).
    \item \textbf{Systolic-Aware StableHLO Tiling:} Programmatic StableHLO matrix multiplier loops matching TPU v5e's 128$\times$128 MXU boundaries, securing an \textbf{88.0\% occupancy rate} (173.4 TFLOPS) \textbf{under simulation, not measured on physical TPU v5e hardware}.
    \item \textbf{Green AI Speculative Scheduler:} A power-aware sampling scheduler that dynamically balances speculation budgets ($K$) against regional grid carbon intensities (France, USA, China).
\end{itemize}

\subsection{2. RunuX: Linux Kernel Translation}
\textbf{Title:} RunuX: A Formally Verified, FFI-Compatible Rust Translation of the Linux Kernel Networking Stack \\
\textbf{Target Venue:} ACM EuroSys '27 (Accepted/Under Review) \\
\textbf{Repository Reference:} Private, \url{github.com/xaviercallens/rust-linux-mini-kernel/tree/main/paper} \\
\textbf{Core Contributions:}
\begin{itemize}
    \item \textbf{297 Translated Modules:} First comprehensive, FFI-compatible Rust translation of the core Linux 5.10 LTS networking stack using binary-compatible \texttt{\#[repr(C)]} FFI bindings.
    \item \textbf{High-Fidelity Chaos Testing:} Statistically identical native boot and packet latency, with \textbf{zero panics/oops} under extensive Chaos Mesh injection (partitions, losses, CPU stalls) on GKE.
    \item \textbf{Lean 4 Formal Verification:} 432 machine-checked theorems across 36 specification modules (138 axioms, 245 open proof obligations as of 2026-09-26); a dedicated 84-theorem Ring-0 isolation model is fully closed with zero \texttt{sorry} and zero axioms. See \texttt{paper/runux\_paper.tex} \S4 for the measured breakdown and the oracle-gated proof-completion methodology used to reduce the open count.
\end{itemize}

\subsection{3. MVK: The Bare-Metal Architecture}
\textit{\small Status (2026-09-26): the full paper is quarantined at \texttt{paper/quarantine/mvk\_scientific\_paper.tex} -- no reproducible \texttt{rdtsc} benchmark harness for the figures below was found in this repository; see \texttt{docs/roadmap/PAPER\_VERIFICATION\_TODO.md}.} \\
\textbf{Title:} Beyond Legacy Abstractions: A Formally Verified, High-Performance Bare-Metal Rust Architecture (MVK) \\
\textbf{Target Venue:} ACM SOSP / ACM Transactions on Computer Systems (TOCS) \\
\textbf{Repository Reference:} Private, \url{github.com/xaviercallens/rust-linux-mini-kernel} \\
\textbf{Core Contributions:}
\begin{itemize}
    \item \textbf{The MVK Kernel:} A 64-bit bare-metal operating system architecture in Rust featuring lock-free Atomic Reference Counting and Sv39/Sv48 paging.
    \item \textbf{Aggressive Optimizations:} Leverages lack of pointer aliasing in safe Rust to allow the LLVM backend to unroll loops, reducing \texttt{mmap} latency by \textbf{25.3\%} and page fault overhead by \textbf{12.2\%}.
    \item \textbf{Zero Latency Drift:} Demonstrates complete immunity to SLAB fragmentation, yielding flatline 45$\mu$s execution loops under 2-hour sustained 100\% CPU stress tests.
\end{itemize}

\subsection{4. MVK: Cyber-Security \& Exploit Eradication}

\textbf{Title:} The Death of the Kernel Zero-Day: Mathematically Eliminating Spatial and Temporal Memory Vulnerabilities in Bare-Metal Architectures \\
\textbf{Target Venue:} IEEE Symposium on Security and Privacy (S\&P) / Dependable Systems \\
\textbf{Repository Reference:} Private, \url{github.com/xaviercallens/rust-linux-mini-kernel} \\
\textbf{Core Contributions:}
\begin{itemize}
    \item \textbf{Spatial and Temporal Immunity:} Structural proof that Rust's lifetime borrow checker eradicates Use-After-Free conditions, and slice indexing validates bounds at compile-time.
    \item \textbf{RCU Data Race Prevention:} Prevents TOCTOU concurrency exploits using a custom compile-time verified lock-free RCU pointer primitive.
    \item \textbf{95\% Attack Surface Reduction:} Quarantines raw hardware IO to $<4.2\%$ of the codebase, leaving the rest verified as purely safe.
\end{itemize}

\textbf{Target Venue:} ACM Transactions on Mathematical Software (TOMS) \\
\textbf{Repository Reference:} Private/Public, \url{github.com/xaviercallens/x-rusty-SUNDIALS} \\
\textbf{Core Contributions:}
